# Provenienta imaginilor

Chei: rafturi, cutii, dosare, dulapuri, sertare, maini, legatura.

Cele sapte imagini sunt originale, generate cu instrumentul imagegen pentru 3s4 la 18.09.2026. Registrul per imagine se afla in `provenienta.json`. Nu sunt fotografii ale depozitului sau echipei clientului. Textele alternative le identifica drept ilustrative. Nu contin active preluate din site-ul de referinta.

Versiuni WebP: 1920 x 1280 si 960 x 1440. Reincadrarea este centrala; imaginile trebuie privite la ambele dimensiuni. Fotografia ilustrativa din antet are o provenienta separata, in `public/art/PROVENIENTA.md`.
